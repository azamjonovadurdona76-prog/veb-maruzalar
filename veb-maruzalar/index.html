📚 Veb tizimlar fanidan ma’ruzalar annotatsiyasi

Guruh: 24-ATT-01 | O‘qituvchi: prof. O‘rinov Sh.R. | Bulutli platforma: Vercel

1-ma’ruza: Veb tizimlar arxitekturasi va HTTP/HTTPS protokollari

Mijoz-server (Client-Server) modeli, DNS tizimi, so‘rov-javob sikli hamda SSL/TLS shifrlash sertifikatlari asoslari.

2-ma’ruza: Frontend texnologiyalari (HTML5, CSS3, JavaScript)

Semantik veb-sahifalar tuzilishi, moslashuvchan (Responsive) dizayn va DOM daraxti bilan interaktiv ishlash.

3-ma’ruza: Backend dasturlash va REST API xizmatlari

Server tomon mantiqi, JSON formatida ma’lumot almashish, marshrutlash (routing) va ma’lumotlar bazasi integratsiyasi.

4-ma’ruza: Bulutli hisoblash (Cloud Computing) va Deploy

IaaS, PaaS, SaaS modellari, CI/CD avtomatlashtirish, CDN tarmoqlari va loyihalarni Vercel/Netlify bulutiga joylashtirish.
